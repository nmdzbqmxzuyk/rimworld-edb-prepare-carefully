## Overview

EdB Prepare Carefully replaces RimWorld's randomized colonist selection screen with a comprehensive editor for designing exactly the starting pawns you want. Customize names, traits, backstories, skills with passion levels, biological ages, relationships between colonists, physical appearance, and starting equipment — then save the configuration as a preset for future playthroughs.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld EdB Prepare Carefully** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Full Pawn Editor** | Edit every attribute of starting colonists before the scenario begins |
| **Trait Control** | Assign any trait combination with awareness of incompatible trait conflicts |
| **Skill & Passion** | Set precise skill levels and passion intensities for each starting colonist |
| **Save Presets** | Save starting configurations as named presets for repeatable starts |
